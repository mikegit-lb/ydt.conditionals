BÖLÜM 1 — Temel Conditional Yapıları

Terminoloji: If-clause = koşul cümlesi. Main clause = sonuç cümlesi. Real = gerçekleşmesi mümkün. Unreal = gerçek dışı varsayım. Counterfactual = geçmişte olmamış şeyin tersini varsayma. V1 / V2 / V3 = fiilin yalın / past / past participle hâli.

1. Zero Conditional

If + present simple, present simple / imperative

Anlam: Genel doğrular, bilimsel gerçekler, alışkanlıklar, kurallar.

Örnek
If you heat water to 100 °C, it boils.
Suyu 100 °C'ye ısıtırsan kaynar.
Tuzak: If-clause'ta will kullanılmaz. ❌ If you will heat water... → ✅ If you heat water...
ALIŞTIRMA
If you ___ ice, it ___.

Cevap: A — heat / melts

Bilimsel/genel doğru → zero conditional → present + present.

2. First Conditional

If + present simple, will / can / may / must / should + V1

Anlam: Gerçekleşmesi mümkün gelecek koşulu.

Örnek
If it rains tomorrow, we will cancel the picnic.
Yarın yağmur yağarsa pikniği iptal edeceğiz.
ALIŞTIRMA
If the new policy ___ next month, employees ___ more flexibility.

Cevap: A — is adopted / will gain

next month → first conditional.

3. Second Conditional

If + past simple (were), would / could / might + V1

Anlam: Şu an veya gelecekte gerçek dışı / hayali durumlar.

Örnek
If I were you, I would apologize immediately.
Senin yerinde olsam hemen özür dilerdim.
Tuzak: If-clause'ta would kullanılmaz.
ALIŞTIRMA
If I ___ a million dollars, I ___ around the world.

Cevap: A — won / would travel

Hayali şimdi → second conditional.

4. Third Conditional

If + past perfect (had + V3), would / could / might + have + V3

Anlam: Geçmişte gerçekleşmemiş durumlar; pişmanlık, eleştiri.

Örnek
If I had studied harder, I would have passed the exam.
Daha çok çalışsaydım sınavı geçerdim.
ALIŞTIRMA
If the team ___ the data more carefully, they ___ such a serious mistake.

Cevap: A — had checked / wouldn't have made

Geçmiş hata → third conditional.

5. Mixed Conditional 5a — Geçmiş → Şimdiki sonuç

If + past perfect, would + V1 (now / today)
Örnek
If I had accepted that scholarship ten years ago, I would be living in London now.
On yıl önce o bursu kabul etseydim şimdi Londra'da yaşıyor olurdum.
ALIŞTIRMA
If the city ___ in public transport ten years ago, traffic ___ so severe today.

Cevap: A — had invested / wouldn't be

ten years ago + today → mixed 5a.

6. Mixed Conditional 5b — Şimdiki → Geçmiş sonuç

If + past simple, would have + V3 (yesterday / last year)
Örnek
If she were more patient, she wouldn't have lost her temper yesterday.
Daha sabırlı olsaydı dün sinirini kaybetmezdi.
ALIŞTIRMA
If he ___ so careless in general, he wouldn't have lost his passport yesterday.

Cevap: A — weren't

in general + yesterday → mixed 5b.

7. Real vs. Unreal

ÖzellikRealUnreal
If-clausePresentPast / Past perfect
Mainwill / can / maywould / could / might
ÖrnekIf you try, you will succeed.If you tried, you would succeed.
ALIŞTIRMA
"If I were a bird, I would fly over the mountains." — Bu cümle hangi türdendir?

Cevap: A — Unreal (hypothetical)

Kuş değilim → hayali şimdi.

8. Modal Verbs in Conditionals

ModalAnlamÖrnek
willKesin gelecekIf you hurry, you will catch it.
canYetenek/izinIf you finish, you can leave.
may / mightOlasılıkIf she calls, she might be late.

ALIŞTIRMA
If she had taken the earlier train, she ___ the meeting, but we cannot be certain.

Cevap: A — might have caught

cannot be certain → düşük olasılık → might have.

BÖLÜM 1B — İleri ve Gizli Conditional Yapıları

Unless / If ... Not

Unless = except if / if not. "…-medikçe." Unless'ten sonra olumsuz fiil kullanılmaz.

Unless the government takes action, the situation will worsen.
Hükümet harekete geçmedikçe durum kötüleşecek.
ALIŞTIRMA
Unless the government ___ stricter regulations, air pollution ___ to rise.

Cevap: A — introduces / will continue

Unless + olumlu present + will. unless + not = çifte olumsuz.

Provided that / As long as / On condition that

Hepsi "…şartıyla / …dığı sürece" anlamı verir; resmî şart belirtir.

You can borrow the car provided that you return it by 8 p.m.
Arabayı ödünç alabilirsin, 20:00'ye kadar getirmen şartıyla.
ALIŞTIRMA
The scholarship will be renewed ___ the student maintains a GPA above 3.5.

Cevap: A — provided that

Resmî şart.

In case / In case of

In case = "olur da … diye" (önlem, koşul değil).

Take some cash in case the card machine doesn't work.
Kart makinesi çalışmazsa diye yanına nakit al.
ALIŞTIRMA
Take a power bank with you ___ your phone runs out of battery.

Cevap: B — in case

Önlem → in case.

Even if / Even though

Even ifEven though
"…olsa bile" (hipotetik)"…rağmen" (gerçek)
ALIŞTIRMA
___ the evidence was overwhelming, the jury acquitted the defendant.

Cevap: B — Even though

Delil gerçekten güçlüydü → gerçek zıtlık.

Only if / If only

Only ifIf only
"Ancak … şartıyla""Keşke"
ALIŞTIRMA
If only I ___ my parents' advice when I was younger!

Cevap: A — had taken

Geçmiş pişmanlık → past perfect.

But for / Without + noun

"…olmasaydı" anlamı; sonuç would (have) V3.

But for your help, I would have failed.
Yardımın olmasaydı başarısız olurdum.
ALIŞTIRMA
___ your timely warning, we would have walked straight into the ambush.

Cevap: A — But for

But for + noun = olmasaydı.

If it were not for / If it had not been for

  • If it were not for + noun → şimdiki varsayım.
  • If it had not been for + noun → geçmiş varsayım.
ALIŞTIRMA
___ the timely intervention of the medical team, the patient ___.

Cevap: B — Had it not been for / would not have survived

Geçmiş varsayım.

ALIŞTIRMA

Cevap: A — Had / might have been made

Inversion past perfect + might have been made.

Wish / If Only

ZamanFormÖrnek
Şimdiwish + past simpleI wish I had more time.
Geçmişwish + past perfectI wish I had studied harder.
Gelecekwish + wouldI wish it would stop raining.
ALIŞTIRMA
I wish I ___ more attention to the safety briefing before the expedition.

Cevap: A — had paid

Geçmiş pişmanlık → wish + past perfect.

Would rather / Would sooner

would rather + V1 (kendi) | would rather + subject + past (başkası) | would rather + have + V3 (geçmiş)
ALIŞTIRMA
I would rather you ___ the matter to the manager before making a decision.

Cevap: A — referred

would rather + subject → past simple.

It's time / It's high time

It's (high) time + subject + past simple
ALIŞTIRMA
It's high time the authorities ___ concrete measures against air pollution.

Cevap: A — took

It's high time → past subjunctive.

BÖLÜM 2 — 28 YDT Sınav Tekniği

Teknik 1 — If Olmadan Koşul: Inversion Avcılığı

Ne: Cümlede if yok ama başta büyük harfle Had / Were / Should varsa gizli conditional'dır.

ALIŞTIRMA
___ the company acted sooner, the crisis could have been avoided.

Cevap: B — Had

Geçmiş varsayım → Had the company acted.

Teknik 2 — Zaman Zarfı Çapası

Ne: now/today → present sonuç; yesterday/ago → past sonuç.

ALIŞTIRMA
If I had invested in that startup in 2015, I ___ financially independent now.

Cevap: A — would be

Mixed 5a: in 2015 + now.

Teknik 3 — "would have + V3" Geçmiş Varsayım İzi

ALIŞTIRMA
Without the new irrigation system, the farmers ___ significantly lower yields last season.

Cevap: A — would have had

Geçmiş varsayım → would have + V3.

Teknik 4 — "Had + V3" If Olmadan

ALIŞTIRMA
Had the researchers ___ the data more carefully, the error would not have occurred.

Cevap: A — analyzed

Had zaten yardımcı fiil → ana fiil V3.

Teknik 5 — Unless'te Çifte Olumsuz Tuzağı

ALIŞTIRMA

Unless + olumlu present + will.

Teknik 6 — Even If vs. Even Though

ALIŞTIRMA

Cevap: B — Even though

Gerçek zıtlık.

Teknik 7 — In Case vs. If

ALIŞTIRMA

Cevap: B — in case

Önlem → in case.

Teknik 8 — But For / Without

ALIŞTIRMA
___ your timely warning, we would have walked straight into the ambush.

Cevap: A — But for

But for + noun = olmasaydı.

Teknik 9 — Otherwise / Or Else

ALIŞTIRMA
The documents must be submitted by Friday; ___, your application will not be considered.

Cevap: A — otherwise

"Aksi halde".

Teknik 10 — Only If Cümle Başında Inversion

ALIŞTIRMA
Only if the committee ___ unanimous approval ___.

Cevap: B — gives / will the project proceed

Only if başta → inversion.

Teknik 11 — If Only = "Keşke"

ALIŞTIRMA

Cevap: A — had taken

Geçmiş pişmanlık.

Teknik 12 — Wish + Past Perfect

ALIŞTIRMA

ALIŞTIRMA

Cevap: A — improves / will take place

ALIŞTIRMA

Cevap: A — won

ALIŞTIRMA

Teknik 25 — Uzun Akademik Cümlede Koşul Avı

ALIŞTIRMA

BÖLÜM 3 — Soru Tiplerinde Conditionals

1. Grammar Gap-Filling

İpuçları: Zaman zarfı → if-clause formu → main clause formu → bağlaç anlamı → eleme.

Örnek
If the new regulations ___ into effect next month, many factories ___ their production methods.
  1. come / will have to change
  2. will come / have to change
  3. came / would have to change
  4. had come / would have had to change
  5. come / had to change
CEVAP A

next month → first conditional.

2. Cloze Test

Örnek
Many developing countries struggle to provide clean water. ___ they invest in modern infrastructure, the problem is likely to worsen over the next decade.
  1. Unless
  2. Even though
  3. In case
  4. Provided that
  5. Whether or not
CEVAP A

Olumsuz sonuç + olumlu eylem → Unless.

3. Sentence Completion

Örnek
If the company had invested in renewable energy a decade ago, ___.
  1. it would be one of the leading green firms today
  2. it will face serious financial difficulties next year
  3. its competitors are currently ahead in the market
  4. the government has offered generous subsidies
  5. environmental regulations were not so strict then
CEVAP A

Mixed 5a.

4. EN→TR Translation

Örnek
If the museum had been renovated earlier, it would attract far more tourists today.
  1. Müze daha önce restore edilseydi, bugün çok daha fazla turist çekerdi.
  2. Müze daha önce restore edilirse, bugün çok daha fazla turist çekecek.
  3. Müze daha önce restore edilmiş olsa da, bugün çok daha fazla turist çekmiyor.
  4. Müze bugün restore edilseydi, daha önce çok daha fazla turist çekerdi.
  5. Müze daha önce restore edilmediği için bugün çok daha fazla turist çekiyor.
CEVAP A

Mixed 5a: "-seydi … bugün -erdi".

5. TR→EN Translation

Örnek
Daha dikkatli olsaydı, dünkü toplantıda bu kadar hata yapmazdı.
  1. If he were more careful, he wouldn't have made so many mistakes at yesterday's meeting.
  2. If he had been more careful, he wouldn't make so many mistakes at yesterday's meeting.
  3. If he is more careful, he won't make so many mistakes at yesterday's meeting.
  4. Unless he were more careful, he would have made so many mistakes at yesterday's meeting.
  5. Even if he had been more careful, he would have made so many mistakes at yesterday's meeting.
CEVAP A

Mixed 5b.

6. Closest Meaning

Örnek
Unless the team members communicate effectively, the project will fail.
  1. If the team members do not communicate effectively, the project will fail.
  2. If the team members communicate effectively, the project will fail.
  3. The project will fail even if the team members communicate effectively.
  4. The team members will communicate effectively only if the project fails.
  5. Provided that the team members communicate effectively, the project will fail.
CEVAP A

Unless = if not.

7. Dialogue Completion

Örnek
A: I should have started earlier.
B: ___ But there's no point in regretting it now.
  1. If you had started earlier, you would have finished on time.
  2. If you start earlier, you will finish on time.
  3. Unless you started earlier, you would finish on time.
  4. If you were starting earlier, you would finish on time.
  5. Provided that you started earlier, you would have finished on time.
CEVAP A

Geçmiş pişmanlık → third conditional.

8. Paragraph Completion

Örnek
Some argue that expanding public transport is the only viable solution. ___, congestion would continue to worsen.
  1. Otherwise
  2. Even so
  3. In case
  4. Provided that
  5. Unless cities invest heavily in public transport
CEVAP E

Olumsuz sonuç + koşul → Unless.

9. Reading Comprehension & 10. Irrelevant Sentence

Parçadaki conditional cümleyi bul → real/unreal durumunu belirle → çıkarımı yap → aşırı genellemeleri ele.

📋 Cheat Sheet — Sınav Öncesi Tek Sayfa

Formüller

Zero: Present → Present
First: Present → will + V1
Second: Past (were) → would + V1
Third: Had + V3 → would have + V3
Mixed 5a: Had + V3 → would + V1 (now)
Mixed 5b: Past (were) → would have + V3 (yesterday)

Inversion

Had I known = If I had known
Were I you = If I were you
Were it not for = If it were not for
Had it not been for = If it had not been for
Should you need = If you should need

Eşdeğerler

Unless = If not
But for = If it were not for
Without = If it were not for
Otherwise = If not

Yasaklar

  • ❌ If-clause'ta will
  • ❌ If-clause'ta would (nazik rica hariç)
  • ❌ Unless + not
  • ❌ In case + will
  • ❌ Wish + will
  • ❌ It's high time + present

Hızlı Çözüm Sırası

  1. Zaman zarfını bul
  2. Fiil formunu kontrol et
  3. Bağlacın anlamını test et
  4. Zaman uyumsuzluğunu ele
  5. Aşırı genellemeleri ele
  6. Bağlamı son kez oku

BÖLÜM 7 — Final YDT Stratejisi

20 En Önemli Kural

  1. Zero = genel doğru → present + present.
  2. First = gerçek gelecek → present + will.
  3. Second = hayali şimdi → past (were) + would.
  4. Third = geçmiş varsayım → had + V3 / would have + V3.
  5. Mixed 5a = geçmiş → şimdi → had + V3 / would + V1 (+ now).
  6. Mixed 5b = şimdi → geçmiş → past / would have + V3 (+ yesterday).
  7. If-clause'ta will yok (nazik rica hariç).
  8. If-clause'ta would yok (nazik rica + if only + would hariç).
  9. Unless = if not; ardından olumlu fiil.
  10. Inversion: Had I known = If I had known; Were I you = If I were you; Should you need = If you should need; Were it not for = If it were not for; Had it not been for = If it had not been for.
  11. But for + noun = if it were not for / had not been for.
  12. Without + noun = if it were not for.
  13. Otherwise / or else = if not.
  14. Even if = olsa bile; even though = rağmen.
  15. In case = diye; in case of + noun.
  16. Only if = ancak şartıyla (başta inversion); if only = keşke.
  17. Wish + past (şimdi) / past perfect (geçmiş) / would (gelecek).
  18. Would rather + V1 / + subject + past / + have + V3.
  19. It's high time + subject + past.
  20. Modal perfect: could/might/must/should have + V3 anlamı değiştirir.

15 En Sık Öğrenci Hatası

  1. ❌ If it will rain... → ✅ If it rains...
  2. ❌ If I would have known... → ✅ If I had known...
  3. ❌ Unless you don't hurry... → ✅ Unless you hurry...
  4. ❌ If I was you... → ✅ If I were you...
  5. ❌ If she studied, she would have passed. → ✅ If she had studied...
  6. ❌ It's high time you go. → ✅ ...you went.
  7. ❌ I would rather you don't smoke. → ✅ ...didn't smoke.
  8. ❌ I wish I would have studied. → ✅ I wish I had studied.
  9. ❌ If I had invested in 2015, I would have been rich now. → ✅ ...I would be rich now.
  10. ❌ If she were more patient, she wouldn't lose her temper yesterday. → ✅ ...wouldn't have lost...
  11. ❌ In case it will rain... → ✅ In case it rains...
  12. ❌ Even though it rains tomorrow, we'll go. → ✅ Even if...
  13. ❌ Only if you study, you can pass. → ✅ Only if you study can you pass.
  14. ❌ But for your help, I would fail yesterday. → ✅ ...would have failed...
  15. ❌ Had I would have known... → ✅ Had I known...

10 En Aldatıcı Çeldirici Kalıbı

  1. If-clause'ta will → doğrudan ele.
  2. If-clause'ta would → doğrudan ele.
  3. Zaman uyumsuzluğu (had + V3 / would V1) → ele.
  4. Ters mixed (had been / wouldn't make) → ele.
  5. Çifte olumsuz (unless + not) → ele.
  6. Yanlış bağlaç (even though + gelecek varsayım) → ele.
  7. Inversion eksikliği (Only if başta, inversion yok) → ele.
  8. But for + clause → ele (but for + noun).
  9. Were it not for vs. Had it not been for → zaman testi.
  10. Aşırı genelleme (all, always, certainly, solely) → ele.

10 En Değerli Tanıma İpucu

  1. Zaman zarfı → now/today vs. yesterday/ago.
  2. Cümle başında Had/Were/Should → inversion.
  3. would have + V3 → koşul geçmiş.
  4. If + had + V3 → sonuç would have + V3 (veya mixed 5a).
  5. Unless → olumlu fiil; not görürsen ele.
  6. But for / without + noun → varsayım.
  7. Otherwise / or else → if not.
  8. Even if / even though → gerçeklik testi.
  9. Only if başta → inversion var mı?
  10. Wish / if only / would rather / it's high time → subjunctive zaman kuralları.

Sınav Günü — 1 Dakikalık Kontrol Listesi

  1. Zaman zarfını bul → now / yesterday / tomorrow / ago.
  2. Cümle başında büyük harf kontrol et → Had / Were / Should?
  3. If-clause'ta will/would var mı? → Varsa ele.
  4. Unless + not var mı? → Çifte olumsuz → ele.
  5. Sonuçta would have + V3 var mı? → Koşul geçmiş olmalı.
  6. Bağlacın anlamını test et → unless / even if / in case / only if / if only.
  7. Zaman uyumunu kontrol et → mixed mi?
  8. Aşırı genellemeleri ele → all, always, certainly, solely.
  9. Kalan iki seçeneği bağlamla karşılaştır.
  10. Son karar → En doğal ve en az zorlama olan seçenek.
